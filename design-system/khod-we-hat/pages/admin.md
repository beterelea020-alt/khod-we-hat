# خد وهات Admin UI

Admin is a distinct operational workspace, not a cosmetic theme. Use compact data tables, strong status chips, bulk-friendly filters, and a right-side details drawer/modal for moderation. Destructive actions require explicit labels and confirmation. Always show current account status and the action audit trail.

Primary areas: overview, users, reports, jobs, exchanges, ads, reviews, skills, categories, analytics, actions, settings.
