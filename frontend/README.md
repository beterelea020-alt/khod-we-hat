# خد وهات — Frontend

Responsive Arabic-first RTL/LTR SPA frontend for the خد وهات skill-exchange platform.

The UI is built around a discovery → matching → exchange → chat → session → review journey, with an Admin Control Center, moderation surfaces, jobs, ads and an in-platform assistant.


## v3 UI

The UI now treats Khod We Hat as an exchange marketplace rather than a skills directory. The main exchange surface supports offers, needs, service/product/time/knowledge categories, matching explanations, proposals, and a dedicated Control Center.
